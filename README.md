# Primas Backtests Operacionais

Site estatico para publicar no GitHub Pages com dados de backtest por operacional, mes, horario e resultado em BRT.

## Estrutura

- `index.html`: pagina principal
- `styles.css`: visual do painel
- `app.js`: leitura dos dados e filtros
- `data/`: CSVs dos operacionais
- `assets/`: logo e favicon

## Dados atuais

O operacional inicial carregado e `Linhas de Ouro - Lote Dobrado`, usando:
